# Finn 2.0 · Campos y controles v3 (C-45)

Copiá esta carpeta como `docs/diseno/campos-v3/` y dale al agente `PROMPT-CAMPOS.md`.

| Archivo | Qué es |
|---|---|
| `PROMPT-CAMPOS.md` | El encargo para desarrollo, con los criterios de aceptación CA-K3-1 a CA-K3-16 |
| `CAMPOS-V3.md` | La especificación: anatomía, medidas, estados, máscaras, textos, accesibilidad y lo que queda abierto |
| `campos-v3.css` | El CSS de referencia, solo con tokens |
| `DECISIONES.md` | El registro completo, con C-45 agregada después de C-44 |
| `referencias/` | La hoja completa (día y noche) y una por sección y tema, en HTML y PNG a 2×, con sus fuentes |
| `logica/` | `motor.js` (máscaras, fechas, validación) y `motor2.js` (reparto entre varias personas), tomados del prototipo |

Secciones de referencia:
- anatomía
- campo con etiqueta
- total, montos y fecha
- selección
- buscador con sugerencias
- casilla, interruptor y opciones
- elección
- fila de parte
- guardar
